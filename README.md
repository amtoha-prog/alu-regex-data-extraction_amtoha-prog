# Data Extraction Tool

## What Does This Do?

This is a program that **finds and organizes information** hidden in messy text.

If you have a pile of messy papers with emails, phone numbers, and links scattered everywhere, this program will:
- **Find all the emails**
- **Find all the phone numbers**
- **Find all the websites/links**
- **Find credit card numbers** (and hide them for safety)
- **Find all the hashtags**

Then it puts all this information into a clean, organized list.


## How to Run It

## Step 1: Open Terminal
Open the terminal/command line on your computer.

## Step 2: Go to the Project Folder
On the terminal write
"cd alu-regex-data-extraction_amtoha-prog"


## Step 3: Run the Program
On the terminal write
"python3 src/main.py"


 The program will start searching.
